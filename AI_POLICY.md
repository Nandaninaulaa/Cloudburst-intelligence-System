
# AI Usage Policy - CloudBurst Intelligence System

CloudBurst Intelligence System supports responsible and
transparent use of Artificial Intelligence tools.

Our goal is to encourage learning, independent thinking,
and meaningful open-source contributions.

## 1. Permitted AI Usage

Contributors may use AI tools for:

- Understanding unfamiliar code.
- Debugging and explaining errors.
- Learning new technologies.
- Improving documentation.
- Generating ideas and exploring solutions.
- Reviewing code for potential improvements.

## 2. AI-Generated Code

AI-generated code is permitted with restrictions.

Contributors must:

- Understand the code they submit.
- Verify that generated code works correctly.
- Test their implementations.
- Check for security vulnerabilities.
- Take responsibility for their contributions.
- Disclose substantial AI assistance when submitting a PR.

## 3. Prohibited Practices

The following are not acceptable:

- Submitting code without understanding it.
- Submitting untested AI-generated implementations.
- Copying sensitive credentials or private information into AI tools.
- Using AI to generate misleading test results.
- Claiming AI-generated work as independently implemented
  when disclosure is required by this policy.

## 4. Pull Request Disclosure

Contributors should mention substantial AI assistance in
their pull request description.

Example:

AI Disclosure:
- Tool used: ChatGPT
- Purpose: Debugging and implementation assistance
- Verification: Manually reviewed and tested

## 5. Maintainer Review

Maintainers may request contributors to explain:

- Their implementation approach.
- Important design decisions.
- How their code works.
- How they tested their changes.

Contributions are evaluated based on correctness,
understanding, quality, and meaningful participation.

## 6. Final Decision

The Project Admin and assigned Mentors reserve the right
to review contributions for compliance with this policy.

Our priority is genuine learning, collaboration,
and responsible AI-assisted development.

Let's build responsibly! 🌩️
